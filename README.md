 AddressBook Spring Boot Application

This is a Spring Boot AddressBook project developed as part of BridgeLabz training.

 Features
- Welcome message API
- Add new contact
- Get all contacts
- Get contact by ID
- Update contact by ID
- Delete contact by ID
- Global Exception Handling

 Tech Stack
- Java
- Spring Boot
- Maven

Project Structure
- controller
- service
- model
- dto
- exception
